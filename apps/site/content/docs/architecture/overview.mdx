## The Courthouse

One Sprite, `probate-courthouse`, that never dies. It runs a FastAPI app on port 8080 with:

- **The clock**: every 15 seconds it charges the [spending cap](/docs/guides/operate#spending-cap), applies Harsh's emailed decisions, and moves the family one step (birth, death, trial).
- **The court and distillation**, which run right after each death.
- **The JSON API** the live site reads ([reference](/docs/reference/api)).
- **The live site** itself: the React app from `apps/web`, served from the same origin.
- **SQLite** at `/home/sprite/data/probate.db`, the index the site reads. Box is the durable archive.

## Generations

One Sprite per life, named `gen-007-grace`. The Courthouse drives it only through the Sprites REST API (exec, filesystem, services), never over HTTP, so a generation's URL stays private. See [How we use Sprites](/docs/architecture/sprites).

## The connector gateway

Every call to an outside service goes to `https://api.sprites.dev/v1/gateway/<provider>/<connection_id>/<path>`. The Sprite sends no Authorization header; the gateway recognises the calling Sprite from Fly.io's request signature and attaches the stored key. See [Connectors](/docs/architecture/connectors).

## Code map

| Package | Does |
| --- | --- |
| `probate.common` | Models, settings, names, prompts, the code bundle, court email helpers |
| `probate.adapters` | The only code that talks to vendors. Each has a fake twin for `PROBATE_FAKE=1` |
| `probate.court` | Layer 1, layer 2, the verdict policy, distillation |
| `probate.generation` | The agent: inbox loop, gate, body checks, CLI |
| `probate.suite` | Fixtures and the per-life runner |
| `probate.courthouse` | Family lifecycle, scheduler, store, budget, API views, simulation |
