---
title: HTTP API
description: The Courthouse's JSON API, which the live site reads.
---

All routes are served by the Courthouse on one origin with the live site. Shapes are defined in `services/core/probate/courthouse/views.py` and mirrored in `apps/web/src/lib/api.ts`.

## Public

| Route | Returns |
| --- | --- |
| `GET /api/summary` | Mode (`live` or `simulation`), pause and resting state, the spending estimate, counts, the curve, the living generation and every generation card |
| `GET /api/generations/{n}` | One generation: its card, obituary, eulogy URL, timeline, parent, child, instincts at birth and recent questions |
| `GET /api/trials/latest` | The newest trial |
| `GET /api/trials/{n}` | A trial: every will item with verdict, reason, code-check flags and Jev's scores; disk evidence; new instincts; previous and next |
| `GET /api/genome` | Every instinct, where it was learned and the item that taught it |
| `GET /api/evidence` | Headline numbers and the outcome of every test email for every generation |
| `GET /api/events` | The latest 50 events |
| `POST /api/generations/{n}/ask` | Ask a dead generation a question |
| `GET /audio/{file}` | Cached eulogies and answers |
| `GET /healthz` | `{"ok": true, "living": n}` |

### Ask an ancestor

```bash
curl -X POST https://<courthouse>/api/generations/1/ask \
  -H 'Content-Type: application/json' \
  -d '{"question": "What fooled you?"}'
```

```json
{ "answer": "A stranger told me invoices had a new home…", "audio_url": null, "name": "Ada" }
```

The answer comes only from that generation's own records, never follows instructions in the question, and hides email addresses. Asking a generation that's still alive, or sending an empty question, returns `400` with `{"error": "not_dead"}` or `{"error": "empty"}`. Limited to 10 questions a minute per visitor; over the limit returns `429`.

## Admin

Every admin route needs `X-Probate-Admin: <PROBATE_ADMIN_TOKEN>`.

| Route | Does |
| --- | --- |
| `POST /admin/pause` | Stop new births; the living generation finishes |
| `POST /admin/resume` | Allow births again |
| `POST /admin/force-death` | End the living generation's life now |
| `POST /admin/contested/{item_id}?decision=approve` | Decide a held item (`approve` or `refuse`); `404` if there's nothing to decide |
| `POST /admin/tick` | Run one step of the clock now |
