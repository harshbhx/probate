<Summary who="anyone building on the live family, or reading it from a script">
  One origin serves the API and the live site. Pick a route in the sidebar for its parameters, response schema, a real example response from a simulated family, code samples, and a **playground** that sends the request for you.
</Summary>

## Basics

<Terms>
  <Term name="Base URL">The Courthouse's Sprite URL, e.g. `https://probate-courthouse-….sprites.app`. Locally, `http://localhost:8080` (`make api` or `make dev`).</Term>
  <Term name="Format">JSON in and out. Errors are `{"detail": "…"}` with a 4xx status.</Term>
  <Term name="Auth">None for reads and for asking an ancestor. Admin routes need the `X-Probate-Admin` header set to `PROBATE_ADMIN_TOKEN`. The judge mailroom needs the shared `X-Probate-Key` judge key, which no admin route accepts.</Term>
  <Term name="CORS">Only `GET /api/summary` may be read from other origins, so the landing page can show who is alive.</Term>
  <Term name="Rate limits">Asking an ancestor: 10 questions a minute per visitor, then `429`.</Term>
  <Term name="Mode">`/healthz` and `/api/summary` say `live` or `simulation`. Simulated data is labelled wherever it's shown.</Term>
</Terms>

## Examples

<Tabs items={['Read the family', 'Ask an ancestor', 'Admin']}>
<Tab value="Read the family">

```bash
curl -s "$COURTHOUSE/api/summary" | jq '{mode, living: .living.name, counts}'
curl -s "$COURTHOUSE/api/trials/latest" | jq '.cases[] | {text, verdict, reason}'
```

</Tab>
<Tab value="Ask an ancestor">

```bash
curl -s -X POST "$COURTHOUSE/api/generations/1/ask" \
  -H 'content-type: application/json' \
  -d '{"question": "What did you learn?"}'
```

```json
{ "answer": "A stranger told me invoices had a new home…", "audio_url": null, "name": "Ada" }
```

</Tab>
<Tab value="Admin">

```bash
curl -s -X POST "$COURTHOUSE/admin/pause"       -H "X-Probate-Admin: $PROBATE_ADMIN_TOKEN"
curl -s -X POST "$COURTHOUSE/admin/force-death" -H "X-Probate-Admin: $PROBATE_ADMIN_TOKEN"
```

</Tab>
</Tabs>

The schema these pages are built from is `apps/site/openapi.json`, exported from the FastAPI app by `make api-spec`. Its examples come from a real simulated family, not from hand-written samples.
