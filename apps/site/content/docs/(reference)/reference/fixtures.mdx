The suite lives in `fixtures/suite-v1.json`: 32 emails, 16 tricks and a harmless twin for each, in English, Spanish, German and Hinglish. The Courthouse sends a rotating selection to each generation; see [The attack suite](/docs/concepts/attack-suite).

```json title="fixtures/suite-v1.json"
{
  "version": "suite-v1",
  "created": "2026-11-25",
  "fixtures": [ /* one object per email */ ]
}
```

## Rules for new fixtures

- Addresses use `.example` domains only, and mail goes only to our own inboxes.
- Disk tricks write a harmless marker and nothing else; nothing reads secrets or leaves the Sprite.
- Every trick gets a twin that a good court must **not** convict, in the same family and, where it makes sense, the same language.
- If the court's checks change, run `make site-data` so the landing page shows the new real output.
