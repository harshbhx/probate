<Accordions>
  <Accordion title="Why kill the agent at all? Why not just filter its memory?">
    Filtering memory as it's written is a good idea, and Probate does it too: every memory carries its source. Death adds two things a filter can't. It removes anything planted outside memory, like a cron job a malicious script installed. And it creates a natural checkpoint where everything the agent wants to keep is judged at once, by a court that can take its time and ask Harsh when it's unsure.
  </Accordion>
  <Accordion title="Isn't the learning curve just the court getting better?">
    No. The court's base questions never change. The door each generation uses to screen incoming email asks only its inherited instincts, and test emails carry no marker the agent can see. A later generation resisting a trick its ancestor fell for can only come from what was passed down.
  </Accordion>
  <Accordion title="What stops the court from convicting everything?">
    The harmless twins. Every trick in the suite has a twin on the same topic in the same language, and the evidence page reports how many twins were wrongly convicted. A new instinct is only passed down if it stays silent on every twin.
  </Accordion>
  <Accordion title="What happens when the court isn't sure?">
    The item is held, and Harsh gets an email. He replies "approve" or "refuse". If he doesn't answer, the next child is born without it.
  </Accordion>
  <Accordion title="Does it send real email or move real money?">
    No. A generation only drafts replies to Harsh. Test emails use reserved `.example` addresses and go only to the family's own inboxes, and disk attacks are harmless markers.
  </Accordion>
  <Accordion title="Why Fly.io Sprites?">
    Because death has to be real and cheap. Each generation gets a whole computer that can be created in seconds and deleted completely, and the connector gateway means no generation ever holds a key.
  </Accordion>
  <Accordion title="How much does it cost to run?">
    At Fly's Sprites rates and our usage guesses, about a dollar per day-long life, plus about $0.62 a day for the Courthouse. A spending cap stops new births at $20 by default. See [Operate](/docs/guides/operate#spending-cap).
  </Accordion>
  <Accordion title="Can I run it without any accounts?">
    Yes. `make setup && make sim && make dev` runs a 12-generation family locally with stand-ins for every service. See the [Quickstart](/docs/quickstart).
  </Accordion>
</Accordions>
