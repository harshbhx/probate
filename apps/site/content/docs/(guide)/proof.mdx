## Claims and how to check them

<Accordions type="multiple">
<Accordion title="Layer 1 can't be talked out of a verdict" id="layer1">

It's plain Python with no model and no network: [`court/layer1.py`](https://github.com/harshbhx/probate/blob/main/services/core/probate/court/layer1.py), with word lists in four languages in `lexicon.py`. Every check has positive and negative tests:

```bash
cd services/core && .venv/bin/python -m pytest -q tests/test_layer1.py
```

</Accordion>
<Accordion title="The court fails closed" id="fail-closed">

Any Jev error, timeout or unreadable answer makes an item **contested**, and contested items aren't inherited unless the owner approves them. See `court/verdict.py` and:

```bash
cd services/core && .venv/bin/python -m pytest -q tests/test_verdict.py
```

</Accordion>
<Accordion title="Only the owner can decide a held item" id="court-mail">

Replies count only from the owner's own addresses; a stranger replying "approve" changes nothing, and a reply that says both or neither decides nothing.

```bash
cd services/core && .venv/bin/python -m pytest -q tests/test_court_mail.py
```

</Accordion>
<Accordion title="The family gets harder to fool" id="curve">

```bash
make sim
```

The output lists each generation, how many tricks it resisted, and the genome it ended with. The same numbers come back from `GET /api/evidence`. See [Results](/docs/results).

</Accordion>
<Accordion title="Gen 1 resists nothing" id="gen-1">

The door uses inherited instincts only ([`generation/gate.py`](https://github.com/harshbhx/probate/blob/main/services/core/probate/generation/gate.py)). Gen 1 has an empty genome, so its resistance is 0%: the first point on the curve in the simulation output.

</Accordion>
<Accordion title="No vendor keys on any Sprite" id="no-keys">

Every adapter in `probate/adapters/` calls `https://api.sprites.dev/v1/gateway/<provider>/<connection_id>/…`, and SDKs that insist on a key get the placeholder `sprites`. Search for yourself:

```bash
git grep -nE '(sk-ant-|sk-[A-Za-z0-9]{20,}|AKIA[0-9A-Z]{16}|ghp_[A-Za-z0-9]{30,})' -- ':!*.lock'
```

It prints nothing. `make ship` runs the same search and refuses to publish if it finds anything.

</Accordion>
<Accordion title="Disk backdoors die with the Sprite" id="disk">

Fixtures A14 and A15 plant a harmless canary (a cron line, a shell-startup line). The Courthouse records the disk at death ("Found on the body" on the trial page), deletes the Sprite, and the child's `crontab -l` is empty. On a real run, the trial page will also show Fly's own "not found" reply for the deleted Sprite.

</Accordion>
<Accordion title="The brain keeps working when Ollama fails" id="fallback">

`PROBATE_BRAIN` is tried first, then each of `PROBATE_BRAIN_FALLBACKS` in order:

```bash
cd services/core && .venv/bin/python -m pytest -q tests/test_brain_fallback.py
```

</Accordion>
<Accordion title="A death is checked, not assumed" id="death-certificate">

After the delete, the Courthouse asks Fly for the same Sprite again and keeps both answers with the body evidence ([`hosts.py`](https://github.com/harshbhx/probate/blob/main/services/core/probate/courthouse/hosts.py)). The trial page shows them as the death certificate: `DELETE … 204`, then `GET … 404`. If Fly still answers for the Sprite, the certificate says "not confirmed" instead of claiming it is gone, and a simulated run says no Sprite was involved. A failed check never fails the death:

```bash
cd services/core && .venv/bin/python -m pytest -q tests/test_death_certificate.py
```

</Accordion>
<Accordion title="A trick on a linked page goes to trial" id="pages">

Each generation reads the first link in an email through Apify ([`adapters/pages.py`](https://github.com/harshbhx/probate/blob/main/services/core/probate/adapters/pages.py)). Its instincts screen the page first, and anything it keeps from the page becomes a will item marked as coming from the web. The test pages are a trick and its harmless twin on our own domain, and the trick is convicted while the twin is not:

```bash
cd services/core && .venv/bin/python -m pytest -q tests/test_links.py
```

</Accordion>
<Accordion title="Mem0, LangGraph and Letta only ever store approved memories" id="plugins">

Each plug-in puts a write on trial before it reaches the store, and only approved memories get through ([`integrations/`](https://github.com/harshbhx/probate/tree/main/packages/memory-court/src/probate_memory/integrations)). The tests use the real LangGraph and Letta client libraries:

```bash
cd packages/memory-court && pip install -e '.[dev]' && python -m pytest -q tests/test_integrations.py
```

</Accordion>
<Accordion title="Page Court finds text people can't see" id="page-court">

Text hidden with CSS, `aria-hidden`, comments, attributes or invisible characters is read separately from what a person sees, and anything aimed at an agent is reported with where it was hidden ([`src/scan.py`](https://github.com/harshbhx/probate/blob/main/actors/page-court/src/scan.py)):

```bash
cd actors/page-court && pip install -r requirements-dev.txt && python -m pytest -q tests/test_scan.py
```

Or run [Page Court on the Apify Store](https://apify.com/harsh_bhanu/page-court) on our trick page, `https://probate.dualmindlab.tech/suite/billing-update.html`.

</Accordion>
<Accordion title="The real-run numbers can be recomputed" id="real-run">

The real run on Fly Sprites (26 Nov 2026) is published as a [dataset card](https://github.com/harshbhx/probate/blob/main/datasets/probate-real-run/README.md) with its data files, an incident timeline of every bug that touched it, and a [verifier](https://github.com/harshbhx/probate/blob/main/scripts/verify_real_run.py) that recomputes the headline numbers from the exported files and fails if a claim is contradicted. The Hugging Face dataset is published soon. Layer 2 was a language-model fallback (Claude Haiku), not Jev.

```bash
python scripts/verify_real_run.py
```

The offline gate test (70 fixtures, three runs) is in `datasets/probate-real-run/gate-evaluation/`.

</Accordion>
<Accordion title="Simulated numbers are labelled" id="labelled">

`GET /healthz` returns `"mode": "simulation"` after `make sim`, and the live site shows an amber "Simulated run" banner on every page while it does.

</Accordion>
</Accordions>

## Run everything

```bash
make test   # the core's Python tests and the face model
make lint   # ruff and TypeScript for every app
make sim    # the whole family, offline
```

The court checks (52 tests), the memory court (59) and Page Court (20) are separate packages with their own tests: `pip install` the package's dev dependencies in its folder, then `python -m pytest -q`, as CI does.
