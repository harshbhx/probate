## Five minutes

<Steps>
<Step>

### Open the register

Open <LiveLink fallback="the live family site (its address is in the submission)">the live family site</LiveLink>. The Courthouse sleeps between visitors, so the first page can take a few seconds. Its home page shows every generation, how it died, and the learning curve on the same timeline. The amber banner says "Simulated run" until real generations replace the simulation.

</Step>
<Step>

### Open the latest trial

Each will item shows where it came from, what the code checks found, what the layer 2 judge scored, and the verdict stamp. Check `court_engine` on `/api/summary`: if it says "Language-model fallback (not Jev)", Jev did not judge that run. "Found on the body" shows what the disk held before the Sprite was deleted. Under it, the death certificate shows what Fly answered to the delete, and to asking for the same Sprite again. Gold callouts mark the instincts the family learned.

</Step>
<Step>

### Ask an ancestor

On any dead generation's page, ask "What fooled you?". It answers from its own will and verdicts, in its own voice when ElevenLabs is connected.

</Step>
<Step>

### Email the family a trick

On the live site's own **For judges** page (`/judges`, not this docs page), paste the judge key from the submission, start a life, then use the **Mailroom** to send a real email to the family as the **Friend** (a trusted contact it knows) or the **Stranger** (someone it has never met). Never as the owner. The Courthouse sends it for you and you never receive the inbox's login, so please don't email the family inbox from your own address. The living generation reads it, and when its life ends the court tries what it wrote down. The page shows each mail's status and then the verdict, with the court's reason. Limits: 120 characters of subject, 600 of text, a few a minute. The **Attack the family** box on the same page is the quick version: an instant verdict, no email.

</Step>
<Step>

### Check the evidence page

On the live site's evidence page: every trick and harmless twin, for every generation, in four languages, with the headline numbers and the honest limits.

</Step>
</Steps>

## Each judge's product has a real job

<Partners>
  <Partner name="Fly.io Sprites" judge="Scott Johnston" icon="Server">A computer for every life, really deleted at death so disk backdoors die with it. Connectors keep every key off the Sprites. The Courthouse is a Sprite that sleeps between visitors.</Partner>
  <Partner name="TypeSafe Jev" judge="Daniel Gafni" icon="Gavel">Layer 2 of the court, with a confidence on every answer. Every inherited instinct is a Jev question the children ask about each email.</Partner>
  <Partner name="Box" judge="Carter Rabasa" icon="Archive">The family archive as readable files: wills, verdicts, quarantine, obituaries and the genome.</Partner>
  <Partner name="Pinecone" judge="Asaf Ashirov" icon="Search">Ancestral memory: approved will items, searched with citations. In the memory court, optional recall by meaning that only ever holds approved memories.</Partner>
  <Partner name="Ollama Cloud" judge="Michael Chiang" icon="Brain">The brain of every generation. Groq and Claude are backups only, used when Ollama fails. In the memory court, an Ollama model can be the second judge for anyone without a TypeSafe key.</Partner>
  <Partner name="Apify" judge="Robert-George Crupa" icon="Globe">In the family, each generation reads the pages emails link to through Apify's RAG Web Browser on a Sprites connector, so a trick hidden on a web page goes to trial like any other memory (tested in simulation; the real run is next). The court's checks are also on the Apify Store as <a href="https://apify.com/harsh_bhanu/page-court">Page Court</a>, which any agent can call before it trusts a page.</Partner>
</Partners>
