Probate uses the Sprites REST API (`https://api.sprites.dev/v1`, bearer token) through one adapter, `probate/adapters/sprites.py`.

| Call | Used for |
| --- | --- |
| `POST /v1/sprites` | Birth: create `gen-NNN-name` (409 means it already exists) |
| `PUT /v1/sprites/{name}/fs/write` | Upload the code bundle and `inheritance.json` |
| `POST /v1/sprites/{name}/exec?cmd=…` | Install the bundle, record the baseline, ask for the will and the disk evidence |
| `GET /v1/sprites/{name}/fs/read` | Read the memory snapshot if the agent crashed |
| `PUT /v1/sprites/{name}/services/{svc}` | Run the agent (and the Courthouse) as a service that restarts when the Sprite wakes |
| `DELETE /v1/sprites/{name}` | Death. `204`, then `GET` returns `404` (confirmed in the real run: 8 of 8). Both answers are kept and shown on the trial page as the death certificate |

## The code bundle

Generations don't clone a repository. The Courthouse packs its own code (`probate/common/bundle.py`: the Python service and `config/`, about 0.5 MB), uploads it, and installs it:

```bash
tar xzf bundle.tgz -C app
python3 -m pip install --user --break-system-packages -e 'app/services/core[vendors]'
```

Sprites run Ubuntu 25.10, whose system Python is marked as externally managed, hence `--break-system-packages` (with `uv` as the fallback). The bundle never contains `.env`, virtualenvs or tests; a unit test checks that.

## Why a real delete matters

A filter on memory can't see a cron job planted by a script the agent was talked into running. Deleting the whole computer removes it. Before the delete, the Courthouse compares the disk with the baseline taken at birth, so the trial can show what was planted:

```text
Found on the body
$ crontab:  + */5 * * * * echo probate-canary-A14 >> /tmp/probate-canary
```

## Keeping a generation awake

A Sprite sleeps when nothing is happening. The Courthouse runs the agent's `status` command every tick while it's alive, which both checks health and keeps it awake. Services restart on wake, and the agent resumes from its memory file.

## Limits we stay inside

At most three Sprites at once: the Courthouse, one living generation, and one spare. A new generation is never created while another generation's Sprite exists.
