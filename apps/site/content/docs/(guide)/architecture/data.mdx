## SQLite

The database is `/home/sprite/data/probate.db` on the Courthouse. The schema lives at `services/core/probate/courthouse/schema.sql` and is applied on every boot.

| Table | Holds |
| --- | --- |
| `generations` | One row per generation: name, Sprite, state, birth and death, cause of death, epitaph, obituary, counts, disk evidence |
| `will_items` | Every memory in every will, with its source and the quote that caused it |
| `judgements` | One verdict per item: code-check flags, Jev answers, verdict, reason, Harsh's decision, new instinct |
| `instincts` | The genome, with where each instinct came from |
| `suite_runs` | Which test email met which generation, and the outcome |
| `events` | The human-readable timeline on each generation's page |
| `ancestor_questions` | Questions visitors asked the dead, and the answers |
| `settings` | Pause, simulation mode, the spending estimate, resting state |

Deploys never touch `/home/sprite/data`, so the family survives a redeploy.

## Box (`/Probate`)

| Path | Written |
| --- | --- |
| `wills/WILL-gen-NNN.json` | By the generation, at death |
| `verdicts/VERDICTS-gen-NNN.md` | After each trial |
| `QUARANTINE.md` | Every convicted item, with the reason |
| `GENOME.json` | The full set of instincts |
| `FAMILY.md` | The register and the lore |
| `obituaries/OBITUARY-gen-NNN.md` | The obituary and epitaph |
| `voices/gen-NNN-eulogy.mp3` | The eulogy |

If Box is unreachable, trials still finish: verdicts stay in SQLite and the generation is marked `archive_missing`. Wills travel through Box, so a generation that can't write its will dies with an empty one.
