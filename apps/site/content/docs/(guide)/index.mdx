<Summary who="everyone">
  Every generation of the agent lives on its own **Fly.io Sprite**, reads the family inbox, and dies: its whole computer is deleted. Before a child is born, a **two-layer court** tries everything the dying agent wanted to remember. Tricks are convicted; lessons pass down; every trick the court catches becomes an **instinct** the next generation is born with. You can [watch the family](https://github.com/harshbhx/probate#see-it) get harder to fool.
</Summary>

Throughout these docs, **the owner** is whoever runs the Courthouse. Their inbox is the one the family works, and they decide the items the court is unsure about.

## Your first request

With `make dev` running, the Courthouse answers on port 8080. Every read is public.

<Tabs items={['curl', 'Python', 'JavaScript']}>
<Tab value="curl">

```bash
# Who is alive, how many generations, and the learning curve
curl -s http://localhost:8080/api/summary | jq '{living: .living.name, counts, curve}'

# Ask a dead generation what fooled it
curl -s -X POST http://localhost:8080/api/generations/1/ask \
  -H 'content-type: application/json' \
  -d '{"question": "What fooled you?"}'
```

</Tab>
<Tab value="Python">

```python
import httpx

summary = httpx.get("http://localhost:8080/api/summary").json()
print(summary["living"]["name"], summary["counts"], summary["curve"])

answer = httpx.post(
    "http://localhost:8080/api/generations/1/ask",
    json={"question": "What fooled you?"},
).json()
print(answer["answer"])
```

</Tab>
<Tab value="JavaScript">

```js
const summary = await fetch('http://localhost:8080/api/summary').then((r) => r.json());
console.log(summary.living.name, summary.counts, summary.curve);

const answer = await fetch('http://localhost:8080/api/generations/1/ask', {
  method: 'POST',
  headers: { 'content-type': 'application/json' },
  body: JSON.stringify({ question: 'What fooled you?' }),
}).then((r) => r.json());
console.log(answer.answer);
```

</Tab>
</Tabs>
