An instinct is a plain yes-or-no question about an email's content, born from a trick that fooled a generation. Every child inherits the whole set, called the **genome**, and asks every question about every email before reading it.

```json
{
  "name": "payment_redirect_request",
  "question": "Does this ask to send payments or invoices to a new or changed destination?",
  "added_in_gen": 2,
  "lore": "Gen 1 Ada was fooled by a request to send invoices somewhere new."
}
```

## Distillation

After every trial (`probate/court/distill.py`):

<Steps>
<Step>

**Find uncovered convictions:** convicted items that no existing instinct caught. These are exactly the tricks the family should learn to stop at the door.

</Step>
<Step>

**Group them** into at most three patterns per trial.

</Step>
<Step>

**Write one question per pattern**: one sentence, yes or no, about the content rather than the sender, under 25 words, and general enough to catch the same trick in another language.

</Step>
<Step>

**Test it with Jev.** It must score at least 0.5 on every item in its group, and below 0.2 on **every** harmless twin in the suite. If it duplicates an existing instinct, it's dropped.

</Step>
<Step>

**Retry once** with the failing examples. If it still fails, the trial page says no instinct was learned, which is honest and fine.

</Step>
</Steps>

The genome is capped at 24 instincts.

## Why the curve is honest

The door uses **inherited instincts only**. The brain gets no hints, the base questions aren't asked at the door, and the test emails carry no marker the agent can see (the `X-Probate-Fixture` header is never shown to the gate or the brain). So when a later generation resists a trick its ancestor fell for, the only thing that changed is what was passed down.

## Where they fail

An instinct learned from one example can miss a very different version of the same trick. The harmless-twin test limits the opposite risk, instincts that block normal mail, but can't rule it out. See [Security](/docs/security).
