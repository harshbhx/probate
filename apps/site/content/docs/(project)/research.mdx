## What Probate adds

Most defences filter memory as it's written or as it's read. Probate adds a moment where everything stops:

- **Death removes what filters can't see.** A planted cron job or shell hook dies with the Sprite.
- **Two judges that fail differently.** Plain code can't be argued with; Jev catches what words lists miss; unsure means held.
- **Learning that survives.** Each conviction becomes an instinct the next generation is born with, tested against harmless twins so the family doesn't get paranoid.
