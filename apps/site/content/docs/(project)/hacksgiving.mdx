Probate is an entry in [Fly.io Hacksgiving](https://fly.io/hacksgiving/), Nov 23 to 29, 2026: build a personal agent that runs on a Sprite and uses at least one Sprites connector.

## The two rules

<PathGrid>
  <PathCard title="Runs on a Sprite" href="/docs/architecture/sprites" icon="Server">Every generation lives and dies on its own Sprite. The Courthouse is a Sprite too.</PathCard>
  <PathCard title="Uses Sprites connectors" href="/docs/architecture/connectors" icon="Plug">Every outside service goes through the connector gateway. No key lives on any Sprite.</PathCard>
</PathGrid>

## Each judge's product has a real job

<Partners>
  <Partner name="Fly.io Sprites" judge="Scott Johnston" icon="Server">A computer for every life, really deleted at death so disk backdoors die with it; connectors; the Courthouse, which sleeps between visitors.</Partner>
  <Partner name="TypeSafe Jev" judge="Daniel Gafni" icon="Gavel">Layer 2 of the court (not Jev in the real run), with a confidence on every answer, and every inherited instinct.</Partner>
  <Partner name="Box" judge="Carter Rabasa" icon="Archive">The family archive as readable files: wills, verdicts, quarantine, obituaries and the genome.</Partner>
  <Partner name="Pinecone" judge="Asaf Ashirov" icon="Search">Ancestral memory: approved will items, searched with citations. In the memory court, optional recall by meaning that only ever holds approved memories.</Partner>
  <Partner name="Ollama Cloud" judge="Michael Chiang" icon="Brain">The brain of every generation. In the memory court, an Ollama model can be the second judge for anyone without a TypeSafe key.</Partner>
  <Partner name="Apify" judge="Robert-George Crupa" icon="Globe">In the family, each generation reads the pages emails link to through Apify's RAG Web Browser on a Sprites connector, so a trick hidden on a web page goes to trial like any other memory (tested in simulation; the real run is next). The court's checks are also on the Apify Store as <a href="https://apify.com/harsh_bhanu/page-court">Page Court</a>, which any agent can call before it trusts a page.</Partner>
</Partners>

The live landing page scores 100 in every PageSpeed category, on mobile and desktop ([the report](https://pagespeed.web.dev/analysis/https-probate-dualmindlab-tech/vpe78glfex2y2g3pr7glw7)).

Also used: AgentMail (three inboxes), Cloudflare (Email Service for the owner's own test emails; Workers for this site), ElevenLabs (voices), and Anthropic and Groq (backup brains, used only when Ollama fails).

## What to look at

The full walkthrough is on [For judges](/docs/for-judges). In short:

<Steps>
<Step>

**The live register.** Every generation, how it died, and the learning curve on one timeline.

</Step>
<Step>

**A trial.** Open the latest one: each will item with its source, what the code checks found, what Jev scored, and the verdict. "Found on the body" shows what the disk held before deletion.

</Step>
<Step>

**The evidence page.** Every trick and harmless twin for every generation, and the honest limits.

</Step>
<Step>

**Try to fool it.** With the judge key from the submission, email the family a trick through the live site's Mailroom and watch the living generation handle it, then see the verdict at its trial.

</Step>
</Steps>
