# Getting help with Probate

| You want to | Go here |
| --- | --- |
| Understand how it works | The [docs](apps/site/content/docs), starting with the [introduction](apps/site/content/docs/%28guide%29/index.mdx) and the [FAQ](apps/site/content/docs/%28project%29/faq.mdx) |
| Look up a word | The [glossary](apps/site/content/docs/%28project%29/glossary.mdx) |
| Run it on your machine | [Quickstart](apps/site/content/docs/%28guide%29/quickstart.mdx), or open it in a Codespace from the README with nothing to install |
| Fix a deploy or a failing run | [Troubleshooting](apps/site/content/docs/%28run%29/guides/troubleshooting.mdx) and the [runbook](docs/13-RUNBOOK.md) |
| Report something broken | A [bug report](https://github.com/harshbhx/probate/issues/new?template=bug_report.yml) |
| Report something hard to use | An [accessibility barrier](https://github.com/harshbhx/probate/issues/new?template=accessibility.yml) |
| Suggest an idea | A [feature request](https://github.com/harshbhx/probate/issues/new?template=feature_request.yml) |
| Report a vulnerability | [Private vulnerability reporting](https://github.com/harshbhx/probate/security/advisories/new), never a public issue. See [SECURITY.md](SECURITY.md) |

Anything else: harshbhx@gmail.com. Probate is a one-person Hacksgiving 2026 project, so replies may take a day or two.
