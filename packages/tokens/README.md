# @probate/tokens

**Internal package.** Private and not published to npm. It holds Probate's design tokens (Night Court v3), shared by the web app, the live site and the docs.

- `theme.css`: the colour, type and spacing tokens.
- `base.css`: base element styles built on the tokens.

Apps in the [repository](https://github.com/harshbhx/probate) import them as `@probate/tokens/theme.css` and `@probate/tokens/base.css`.
